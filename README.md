# Leorenzo Guiral | Portfolio

Personal portfolio of Leorenzo Guiral, a 2nd-year BSIT student from the Philippines who builds small web apps, analyzes data, edits video and produces music.

**Live site:** https://leorenzo-guiral.vercel.app/

## Features

- Glass-style design with a green accent and a soft glowing background
- Typing animation in the hero section
- Sections for services, skills, education, projects and certificates
- "Hire me" popup form that sends messages straight to my inbox through Formspree
- Download button for my CV
- Responsive layout with a mobile menu

## Built with

- HTML, CSS and JavaScript (no frameworks)
- [Font Awesome](https://fontawesome.com/) for icons and [Poppins](https://fonts.google.com/specimen/Poppins) from Google Fonts
- [Formspree](https://formspree.io/) for the contact form
- [Vercel](https://vercel.com/) for hosting, deployed from this repo

## Project structure

```
index.html                    page content
style.css                     styling
script.js                     typing effect, menu, and contact form
main.jpg                      profile photo
Leorenzo_Guiral_Resume.pdf    downloadable CV
```

## Run it locally

No install needed. Download or clone the repo and open `index.html` in a browser.

```
git clone https://github.com/leorenzo1/Portfolio.git
```
